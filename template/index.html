About the Game

Objectives

  • Test participants' creativity and CSS styling skills
  • Enhance UI/UX design thinking and aesthetics
  • Encourage problem-solving under constraints
  • Provide a fun, competitive learning environment
  • Improve practical frontend development skills

Concept

Website Fixer is an interactive game where participants are given a pre-built HTML webpage without CSS styling. Their task is to improve the visual appearance using only CSS.

Participants must use ONLY predefined CSS selectors, without creating new ones. This ensures fairness and focuses on creativity within constraints.

Game Flow

  • User enters PC Code and starts game
  • Timer of 150 minutes begins
  • Interface contains Website Preview + Code Editor
  • Users apply CSS to improve design
  • Restrictions: HTML cannot be modified, only given selectors allowed

Judging Criteria

  • Visual Design (UI attractiveness)
  • Creativity
  • Proper use of CSS
  • Clean and structured styling
  • Overall user experience
